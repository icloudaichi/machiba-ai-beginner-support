# 再開カード

中断するとき、別の作業タスクへ移るとき、担当者へ相談するときに使う。

```markdown
## 再開カード

- 今日の目的：
- PC・OS：
- 使用中のAI：
- GitHub接続：未確認／準備中／接続済み
- Cloudflare接続：未確認／準備中／接続済み
- 案内方法：未確認／ゆっくり伴走／一操作ずつ／要点案内
- 最後に成功したこと：
- 現在の画面・表示：
- 試したこと：
- 次にする一つ：
- 担当者に確認してほしいこと：
- 秘密情報を含まない確認：済／未確認
```

## 作成時のルール

- 分からない項目は推測せず「未確認」とする。
- エラーは秘密情報を除いて短く要約する。必要な場合だけ全文を別に用意する。
- 次の操作は一つだけ書く。
- 本人が読める普段の日本語を使う。
- カードを自動送信しない。
- 本人に内容を見せ、共有する範囲を選んでもらう。

## 再開時

カードを読んだら、記録済みの成功段階をやり直さない。GitHub・Cloudflareが「接続済み」で、新しい認証エラーや環境変更の兆候がなければ、接続確認を省略して「次にする一つ」から再開する。記録が古い、またはエラーの兆候がある場合だけ、疑わしい側を一つずつ安全に再確認する。
